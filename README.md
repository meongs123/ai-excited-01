# Celestial Angel — Scattering Planets (v2-r1) — ai-excited-01

A timeless winged celestial being, face half in shadow and lit by a sharp
rim light, scattering seven large glowing worlds — one of them ringed —
from an open hand down a bold arc into a spiral galaxy below. The planets
are big enough to read at thumbnail size; the idea hits in one look: a
hand holding worlds, a galaxy for a floor.

`main.ts` copies `entry.png` to the output directory byte for byte — no
network, no randomness, no re-encoding — and checks the copy first: file
size within 1 MiB, dimensions within 1024×1024, PNG or JPEG magic bytes,
and a sha256 match against the source before it reports success.
